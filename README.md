# 🏎️ Velozaar

> **"MADE BY SOU."**

**Velozaar** is a fast-paced, single-file 3D browser game built with **Three.js (WebGL)**, **Tailwind CSS**, and a procedural **Web Audio API Synthesizer**. Tear down an endless ash-grey highway in a customized ride or take to the skies in a pastel hot air balloon—complete with voxel blasters, continuous world-edge wrapping, and an Apple iOS glassmorphic HUD.

---

## ✨ Features

* **🚘 Custom Garage:** Choose from **4 distinct vehicle body types** (*Sports Coupe*, *Muscle GT*, *Cyber SUV*, and *Formula Apex*) and **6 custom paint finishes** (*Crimson Blaze*, *Electric Cobalt*, *Emerald Neon*, *Royal Amethyst*, *Solar Gold*, and *Pearl Titanium*) with a live 3D preview.
* **🚚 Diverse Traffic Fleet:** Dodge or blast through 5 distinct highway vehicle classes—**Heavy Semi-Trucks**, **City Transit Buses**, **Motorcycles with Riders**, **Off-Road Pickups**, and **Compact Hatchbacks**—dynamically generated so they never clash with your car's body style or paint color.
* **🎥 Multi-Angle Camera System:** Cycle seamlessly between **Chase Cam**, **Hood / Cockpit Cam**, **Top-Down Cam**, and **Action Wide Cam** using the `C` key on PC or the on-screen `CAM` button on mobile.
* **🎈 Dual Game Modes:** Switch anytime between **Car Highway Mode** and **Hot Air Balloon Mode** (featuring animated flocking origami birds).
* **🌍 4 Dynamic Biomes (Geotypes):**
  * 🌸 **Pastel Meadow** — Mint fields & falling sakura petals.
  * ❄️ **Snow Wonderland** — Glaciers, snowmen, ice crystals & snowfall.
  * 🫧 **Underwater Reef** — Coral branches & rising sea bubbles.
  * 🏜️ **Sunset Canyon** — Peach mesas, cacti & desert dust.
* **♾️ Continuous World Wrapping:** Steer off the far left or right edge of the highway to warp seamlessly to the opposite side while randomizing the surrounding terrain.
* **💥 Voxel Blaster & Physics:** Fire energy orbs to shatter traffic obstacles and birds into bouncing 3D voxel shards.
* **🔊 Procedural Web Audio Synth:** 100% code-generated engine hums, laser pews, voxel crunch explosions, and UI chimes with zero external audio files required.
* **📱 Cross-Platform Adaptive UI:** Dedicated **Laptop / PC Keyboard** mode and **Smartphone / Tablet Touch** mode with glassmorphic pedals and steering buttons.

## 🎮 Controls

| Action | Laptop / Desktop PC | Smartphone / Tablet (Touch UI) |
| :--- | :--- | :--- |
| **Steer Left / Right** | `←` `→` or `A` `D` | On-Screen **Left / Right** Buttons|
| **Accelerate / Boost** | `↑` or `W` | On-Screen **Accel** Pedal |
| **Brake / Slow Down** | `↓` or `S` | On-Screen **Brake** Pedal |
| **Fire Voxel Blaster** | `SPACEBAR` | On-Screen **BLAST** Trigger |
| **Switch Camera View** | `C` Key | On-Screen **CAM** Button |
| **Hot Air Balloon Mode** | `B` Key | Main Menu Card |
| **Quick Respawn** | `SPACEBAR` or `ENTER`| **Respawn** Button |

## 🛠️ Tech Stack

* **3D Engine:** [Three.js (r128)](https://threejs.org/).
* **Styling & HUD:** [Tailwind CSS](https://tailwindcss.com/) + Custom iOS Glassmorphism CSS.
* **Audio:** Native HTML5 Web Audio API (`AudioContext` oscillators & noise buffers).
* **Icons & Fonts:** [Font Awesome 6](https://fontawesome.com/) & Google Fonts (`Inter` & `Plus Jakarta Sans`).
