# Velozaar 🏎️☁️

**Velozaar** is a high-performance, dual-odyssey 3D browser game and interactive experience built with **Three.js** and **Tailwind CSS**, designed and engineered by **@sca4s**. 

Explore two unique immersive game modes: **The Endless Highway** (high-speed vehicular racing against multi-lane traffic) and **Beyond the Fearless Sky** (soaring above a crystal valley river between twin mountain ridges).

---

## Features

* **Dual-Odyssey Gameplay**: Switch between Car Mode (The Endless Highway) and Sky Mode (Beyond the Fearless Sky) seamlessly.
* **3D Showroom & Bespoke Customization**: Interactive 3D turntable preview, 4 highway chassis options, 4 aerial sky craft, and a multi-color pastel palette builder.
* **Dynamic Geotypes & Biomes**: Explore Pastel Meadow, Snow Wonderland, Underwater Reef, and Sunset Canyon with day/night atmospheric lighting modes.
* **Integrated Web Audio Synth**: Zero external dependencies—procedurally synthesized engine hums, laser pew effects, voxel explosion crunches, and wrap chimes using the Web Audio API.
* **Multi-Camera Perspectives**: Switch instantly between Chase Cam, Hood/Cockpit Cam, Top-Down Cam, and Action Wide Cam.
* **Fully Responsive Controls**: Optimized support for both Touch UI (smartphones/tablets) and Keyboard/Mouse (laptops/desktops).
* **Individual HUD Control & Session Saves**: Toggle and hide any HUD element individually, use the centralized *Unhide All UI* button, and automatically save gameplay progress on pause.

---

## Controls

### Keyboard & Mouse (PC / Laptop)
* **← / →** or **A / D**: Steer Left / Right
* **↑ / ↓** or **W / S**: Accelerate / Brake
* **Spacebar**: Fire Blaster / Respawn
* **C**: Cycle Camera Perspective
* **B**: Cycle World Geotype (Biome)
* **N**: Toggle Day / Night Sky Mode
* **T**: Toggle White / Dark UI Glass Theme
* **P** or **ESC**: Pause / Resume Odyssey

### Touch Interface (Mobile / Tablet)
* Use on-screen left/right steering pads, acceleration/brake pedals, camera toggle button, and blaster button.
